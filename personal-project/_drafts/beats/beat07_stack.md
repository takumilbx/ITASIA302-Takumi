# Beat 07 · The Stack

## Copy
- Meta: 07 · The Stack
- Headline: The *tools* I use
- Intro: Five tools, in the order work moves through them. A source enters left, exits as a note you can find.
- Tool focus cards (own system, no external citations):
  1. Zotero · Capture. Reference manager. Every source enters with its PDF, metadata, and an auto-generated citekey. The Obsidian Zotero Integration plugin drops a structured import note into the vault inbox.
  2. Obsidian · The vault. Plain-text markdown notes linked into a graph. Atoms, molecules, alloys all live here, reached by search and backlink, not folders.
  3. Claude Code · The operator. Reads the literature note, opens the PDF, runs extraction, verifies every candidate against the source before anything enters the vault.
  4. NotebookLM · The extractor. Focused queries over MCP. It can only answer from the given source, so claims stay honest.
  5. Notion · The calendar. Thesis chapters, fieldwork milestones, deadlines, all linked back to vault notes by citekey. Obsidian is the brain. Notion is the calendar.

## Personal essay
The stack looks like tool clutter until you notice each tool holds a different kind of trust. Zotero I trust with provenance. Obsidian I trust with meaning. The AI layer I deliberately do not trust: everything it extracts gets checked against the source page before it becomes an atom. That distrust is a feature. An assistant that can only answer from the paper in front of it is an assistant that cannot invent my thesis for me.
