## Copy
- Meta: 09 · The Method
- Headline: The *framework* I apply
- Intro: A Zettelkasten built retrieval-first, not capture-first like Forte's CODE and PARA [cite:FORTE-02]. Knowledge climbs three tiers. Nothing moves up until the tier below holds.
- Tier focus cards:
  1. Atom. One idea, one exact quote, one source. The filename is the claim written as a full declarative sentence, so search alone can find it. The vault holds 2,163 of these [cite:VAULT-01].
  2. Molecule. Two to five atoms on a shared theme, linked into one note. It adds no new claims, only the relations between existing ones.
  3. Alloy. An original, thesis-grade synthesis built from molecules and atoms. It can never be drafted directly from a source. The research output lives here.

## Personal essay
Forte's CODE moves material toward expression, and PARA sorts it by actionability. Both are capture-first at heart: they optimize the inbox. My tiers optimize the exit. The rule that nothing moves up until the tier below holds sounds bureaucratic, but it is the honesty mechanism of the whole system. An alloy built on unverified atoms is just an opinion with footnotes.
