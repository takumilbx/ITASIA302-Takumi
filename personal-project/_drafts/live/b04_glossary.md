Six things I use. Each one on its own first, then how they fit together.

## [gk4] gk
Obsidian

## [gd5] gd
An application that reads a folder of plain text files, the markdown files on my laptop. It draws the links between notes and lets me search them quickly. The important part is that Obsidian does not own your files. If I change devices, or change apps, I do not lose anything, as long as I still have the files themselves.

## [gk6] gk
Vault

## [gd7] gd
The name for the folder that holds those markdown files. I use markdown because it is a file type a machine can read easily, unlike a PDF, which eats a lot of context.

## [gk8] gk
Zotero

## [gd9] gd
If you read a lot of academic articles, or keep a lot of literature sources, Zotero is one of the applications many researchers use. It stores the PDFs and the other publication files. There is a Chrome extension, so when I find something interesting I click save once and it imports the file and all of its metadata. It also helps when I am writing, because the citation is already there, and anything I highlight in a PDF is kept with it.
