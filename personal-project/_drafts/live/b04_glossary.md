## [body3] body
Six things I use. Each one on its own first, then how they fit together.

## [gk4] gk
Obsidian

## [gd5] gd
An application that reads a folder of plain text files, the markdown files on my laptop. It draws the links between notes and lets me search them quickly. The important part is that Obsidian does not own your files. If I change devices, or change apps, I do not lose anything, as long as I still have the files themselves.

## [gk6] gk
Vault

## [gd7] gd
The name for the folder that holds those markdown files. I use markdown because it is a file type a machine can read easily, unlike a PDF, which eats a lot of context.

## [gk8] gk
Zotero

## [gd9] gd
If you read a lot of academic articles, or keep a lot of literature sources, Zotero is one of the applications many researchers use. It stores the PDFs and the other publication files. There is a Chrome extension, so when I find something interesting I click save once and it imports the file and all of its metadata. It also helps when I am writing, because the citation is already there, and anything I highlight in a PDF is kept with it.

## [gk10] gk
Claude Code

## [gd11] gd
A command line tool from Anthropic, built for programming. I use it to manage the files on my computer. Claude chat, and other AI tools, cannot reach my local files at all. Claude Cowork can reach them, but it does its work inside a sealed environment and moves the files in and out of it [[(Anthropic, 2026)]]. Claude Code works on the files where they already are [[(Anthropic, n.d.)]]. For me that is noticeably faster, and it is how this website was built.

## [gk12] gk
NotebookLM

## [gd13] gd
I use it to ask questions about a single paper. It is quite common now. People use it to summarise a paper, to find the argument inside it, or to turn something complicated into a video summary or a podcast so it is easier to take in. For me the most powerful part is how it works. It only references what is in the document I gave it, so in my experience I have not caught it inventing anything, unlike other platforms.

## [gk14] gk
Notion

## [gd15] gd
A landing page where I keep everything together. It references the data from my Obsidian vault. I use it to summarise the arguments in my thesis and to track the logical flow of the thesis. The vault has a lot of claims in it. The Notion page only has the selected ones, presented so that you can move around and read them easily.
